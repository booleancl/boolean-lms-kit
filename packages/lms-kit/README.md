# @boolean/lms-kit

Frontend de [boolean-lms-kit](https://github.com/booleancl/boolean-lms-kit): editor CodeMirror 6, runners
(Pyodide, JavaScript, SQLite), planilla de cálculo, reveal.js y el plugin de Vite `@boolean/lms-kit/vite`.

Se usa junto a la gema `jekyll-boolean-lms-kit`. Se distribuye como tarball en las
[GitHub Releases](https://github.com/booleancl/boolean-lms-kit/releases); instalación y documentación
en el [README del repositorio](https://github.com/booleancl/boolean-lms-kit#readme).
