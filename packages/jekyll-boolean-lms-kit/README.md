# jekyll-boolean-lms-kit

Plugin de Jekyll de [boolean-lms-kit](https://github.com/booleancl/boolean-lms-kit): generator de páginas
interactivas desde archivos `.py`/`.js`/`.sql`/`.csv`, Liquid tags (`{% python_example %}`, `{% slides %}`…),
layouts e includes.

Se usa junto al paquete npm `@booleancl/lms-kit` (frontend + plugin de Vite). Instalación y documentación
en el [README del repositorio](https://github.com/booleancl/boolean-lms-kit#readme).
